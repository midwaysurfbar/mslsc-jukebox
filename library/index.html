Sort songs into decade folders

Looks up when each song first came out, then moves it into its decade folder (1970s, 1980s…). The song picker's decade buttons follow straight away.

Only songs with the singer or band in their name are looked up: a song name on its own too often matches the wrong song. Use the No singer or band filter on Songs to fix those, and they'll sort next time. iTunes only answers about 20 lookups a minute, so a big folder takes a while. It keeps going on the Jukebox even if you close this page. Nothing moves until you press Move.
